# Verificação

Execute os comandos definidos em `package.json`.

## Verificação completa

```bash
npm run check
```

Roda lint, typecheck e testes em sequência.

## Comandos individuais

```bash
npm run lint
npm run typecheck
npm test
npm run format
npm start -- <participantes> <duracao-minutos> <custo-por-hora>
```

Detalhes de domínio e casos de borda: `.agents/skills/add-calculation-case/SKILL.md`.
